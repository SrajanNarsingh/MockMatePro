# MockMate Pro frontend

React + Vite frontend prototype for the Phase 1 academic project.

## Run on Windows

1. Extract this ZIP.
2. Open the extracted `MockMatePro_Frontend_Checked` folder in VS Code. The `package.json` is in this top-level folder.
3. Open Terminal > New Terminal and run:

```powershell
npm.cmd install
npm.cmd run dev
```

4. Open the local URL printed by Vite, usually `http://localhost:5173/`.

To verify the production build after dependencies install:

```powershell
npm.cmd run build
```

## Demo mode and backend contract

When `VITE_API_BASE_URL` is blank, the app uses local sample questions and illustrative feedback. This is not real AI evaluation and does not persist sessions to MongoDB.

When the backend is ready, copy `.env.example` to `.env`, set `VITE_API_BASE_URL=http://localhost:5000` (or the actual backend URL), then restart Vite.

Expected endpoints:

- `POST /api/interviews` with `{ "role": "Frontend Developer", "difficulty": "Intermediate" }`, returning an interview object with `_id` or `id` and `questions`.
- `POST /api/interviews/:id/answers` with `{ "questionId": "q1", "question": "...", "answer": "..." }`, returning `{ "feedback": "...", "score": 7 }`.

## Current limitations

This is a frontend prototype. Demo feedback is illustrative, not generated by an AI model. Live API calls, AI integration, database persistence, and the full production build must be verified with the team's backend and local environment before claiming them as complete.
